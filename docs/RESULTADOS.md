# Indicadores e apresentação de resultados

## Pergunta que cada indicador responde

| Indicador | Pergunta |
| --- | --- |
| Progresso geral | Quanto do plano já foi executado? |
| Cobertura | Quantas áreas do modelo possuem dados confiáveis? |
| Horas registradas | Existe consistência de estudo? |
| Tarefas concluídas | O aprendizado virou execução prática? |
| Evidências | Há comprovação verificável das entregas? |
| Nível de competências | A capacidade está evoluindo até a meta? |
| Revisões concluídas | O plano está sendo inspecionado e ajustado? |
| Certificações | Há validação externa do conhecimento? |

## Regra do progresso consolidado

O indicador combina apenas domínios com dados. Os pesos atuais são:

- objetivos: 25%;
- trilhas: 20%;
- conteúdos estudados: 15%;
- projetos: 20%;
- competências: 10%;
- revisões: 10%.

A cobertura evita apresentar um percentual enganoso quando ainda faltam dados
em parte do plano.

## Relatório executivo

A rota `/indicadores/relatorio/` oferece uma apresentação limpa para entrevistas
e revisões:

- direção e objetivo profissional;
- progresso atual;
- horas, projetos, evidências e pendências;
- projetos e competências em destaque;
- resumo numérico;
- impressão ou exportação para PDF pelo navegador.

## Como apresentar em uma entrevista

1. comece pelo problema: PDI estático não evidencia execução;
2. mostre o ciclo objetivo → estudo → projeto → evidência → indicador;
3. abra um roadmap gerado de PDF;
4. conclua uma etapa e explique o recálculo;
5. abra um projeto e sua evidência;
6. finalize no relatório executivo;
7. mostre arquitetura, segurança e monitoramento no repositório.

## Integridade dos números

Indicadores são calculados diretamente dos registros do sistema. Dados
demonstrativos devem ser identificados como tais. Resultados reais nunca devem
ser inflados ou misturados com dados corporativos confidenciais.
